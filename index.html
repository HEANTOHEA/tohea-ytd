Connect this frontend to your private backend server (Render, Railway, Fly.io, or localhost). This enables direct, high-quality 320 Kbps MP3 downloads without ads or third-party redirects.

Free Cloud Deployment (Render):

  1. Push this repository to your GitHub account.
  2. Go to Render.com → New + → Web Service.
  3. Connect your repo and choose Docker runtime (uses the included Dockerfile).
  4. Click Deploy and copy your live URL into the box above!

Telegram Mini App Setup

How to run your YouTube Music Downloader inside Telegram with your Cloud Backend:

4 Steps:

  1. Deploy Backend: Deploy this repo to Render or Railway (free Docker web service).
  2. Host Frontend: Deploy frontend to GitHub Pages or directly use the URL provided by Render!
  3. Open @BotFather: In Telegram, chat with @BotFather, send /newapp, and paste your URL.
  4. Enjoy In-App Downloads: Open the Mini App in Telegram → paste any YouTube link → tap Download to get MP3s directly on your phone!
